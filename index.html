Searches worth running by hand

Most large Indian employers run Workday, Darwinbox or Naukri RMS, none of which publish a feed. The LinkedIn and Indeed pull above reaches some of them, but only the top results per search. These links run the same searches in full, with the entry-level and last-30-days filters applied, sorted newest first.

How this was built

Sources
Greenhouse, Lever and Ashby public board APIs, plus LinkedIn and Indeed search results pulled with JobSpy. Search rows are marked via LinkedIn or via Indeed. A role that drops out of a search has not necessarily closed, so only board roles are tracked to closure.
Experience
Parsed from each posting's own description, not inferred from its title. Product Manager is a graduate role at one company and a four-year role at the next.
